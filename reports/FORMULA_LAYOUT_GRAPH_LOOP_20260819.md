# 공식 배치 그래프 개선 루프

## 결론

- 문자 확정 결과 뒤에 독립적인 `공식 배치 그래프 → LaTeX 직렬화` 레이어를 추가했다.
- 배치 그래프는 문자 모델의 순서나 예측으로 되먹임하지 않는다. 되먹임 실험은 외부 문자 정확도를 낮춰 기각했다.
- 직접 수집 95식의 구조 오탐은 6개 관계에서 0개로 줄었다.
- CROHME 비상업 진단에서 관계 완전일치는 539/984식에서 551/984식으로, 관계와 문자를 함께 맞춘 엄격 식 일치는 220/984식에서 224/984식으로 증가했다.
- 아직 `shadow_runtime_only`다. 프로젝트 소유 복합식 관계 정답이 0식이므로 상용 기본 경로 승격 근거는 부족하다.

## 고정 구조

```text
온라인 stroke
  → 불변 문자 후보와 HWR Top-5
  → r6 문맥·문법 문자 확정
  → 공식 배치 그래프(분수·루트·위첨자·아래첨자)
  → 후보 보존 LaTeX
```

- 배치 입력: 문자 박스, HWR Top-k, 이미 확정된 Top-k 내부 문자.
- 배치 출력: 식별자별 관계 그래프, 기하 순서, LaTeX.
- 금지: 새 문자 생성, 문자 삭제, stroke ownership 변경, 문자 모델로의 피드백.
- 중첩 분수·루트는 한 문자가 여러 상위 영역에 속할 수 있도록 비배타 관계로 표현한다.
- 다중 부모 노드는 식별자와 부모 관계를 출력 감사에 남긴다. 이 경우 LaTeX는 `shadow_ambiguous_multi_parent`이며 확정식으로 취급하지 않는다.
- 여는 괄호를 첨자 기준으로 삼거나 등호·중위 연산자를 고립 첨자로 올리는 경우는 Top-k 확률로 보수적으로 거부한다.
- 루트 안에 여는 괄호만 잡히고 닫는 괄호가 빠진 경우에는 불완전 루트 포함 관계를 만들지 않는다.

- 확장된 관계 순서를 문자 문맥 모델에 되먹인 분기: CROHME 문자 Top-1이 78.8568%에서 78.7520%로 하락해 기각.
